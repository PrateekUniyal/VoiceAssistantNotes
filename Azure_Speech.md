# Azure Speech Services

## Overview
Azure Speech Services is part of the **Azure AI** suite.

## Key Features
- Converts **voice to text**
- Understands spoken input and can **act on it**
- Supports both:
  - **Speech-to-Text**
  - **Text-to-Speech**

---

# Speech-to-Text

### Features
- **Real-time transcription**
- Support for **many languages and accents**
- **Domain-specific vocabulary** available
- Works on **different devices** and across **multiple platforms**
